HYBRID ATHLETE — PWA v1
=======================

Wymagania:
- Hosting statyczny HTTPS (np. GitHub Pages, Netlify, Cloudflare Pages) do instalacji PWA.
- Alternatywnie localhost na komputerze do testowania.
- Po pierwszym uruchomieniu online, aplikacja buforuje pliki przez service worker i działa offline.
- Dane dziennika i rekordy zapisują się lokalnie w przeglądarce (localStorage).
- Brak automatycznej synchronizacji pomiędzy telefonem i komputerem.
- Regularnie wykonuj eksport JSON z zakładki Rekordy.

Instalacja iPhone:
1. Opublikuj zawartość tego folderu na hostingu HTTPS.
2. Otwórz adres w Safari przy dostępie do internetu.
3. Menu Udostępnij -> Dodaj do ekranu początkowego.
4. Otwórz aplikację z ikony; przetestuj tryb samolotowy.

Uruchomienie lokalne na komputerze:
  python -m http.server 8000
  http://localhost:8000
